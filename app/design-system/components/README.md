# Componentes

Guías de uso de cada componente: qué es, qué clases lleva y cuándo usarlo. Las clases son las de
[`../../src/styles/`](../../src/styles/) (un archivo por zona), que es la referencia viva; aquí no hay una copia aparte de los estilos.

| Componente | Para qué |
| --- | --- |
| [Avatar](Avatar.md) | Foto de perfil o inicial sobre un tono que sale del nombre |
| [Badge](Badge.md) | Etiqueta de estado («Tuya», «Anónima», «Eliminada») |
| [Banner](Banner.md) | Aviso de una línea: votación cerrada, modo demo |
| [Button](Button.md) | Acciones: `primary`, normal y `danger` |
| [Chip](Chip.md) | Filtros y elección múltiple |
| [DayCell](DayCell.md) | Casilla del calendario, partida por opciones |
| [Dialog](Dialog.md) | Confirmación de una acción importante |
| [Fab](Fab.md) | Botón flotante: el chat y «Nueva votación» en el móvil |
| [InfoButton](InfoButton.md) | Botón ⓘ con información aparte |
| [Input](Input.md) | Campos de texto, desplegables y áreas de texto |
| [PollCard](PollCard.md) | Tarjeta de una votación en «Mis votaciones» |
| [PremiumTag](PremiumTag.md) | La estrella de premium |
| [RankingRow](RankingRow.md) | Fila de «Opciones más votadas» |
| [SidebarItem](SidebarItem.md) | Grupos y votaciones del menú lateral |
| [Tiebreak](Tiebreak.md) | Tarjeta del desempate |
| [Toast](Toast.md) | Aviso flotante breve |

El design system también está publicado como artifact, con vistas previas de cada componente en los dos temas:
https://claude.ai/artifact/MjUiWfD5vrkky24RQvPgfV. La referencia es este repositorio: si el artifact no coincide, manda
lo de aquí.
