# Input

Campo de texto, desplegable o área de texto con borde `line` sobre `card`; `big` para el nombre de la votación.

- Uso: `<input class="input">`, `<select class="input">`, `<textarea class="input">`. Tamaños `big` y `small` (este de ancho automático).
- Siempre a 16px o más, para que el móvil no haga zoom al escribir.
- Al enfocar, borde y anillo en `focus`. El `placeholder` (en `muted`) es un ejemplo («Ej.: Comida», «Ej.: Cena de Navidad 2026 🎄») o la ayuda de un campo opcional, nunca un valor ya escrito: lo que se guarda es lo que la persona escribe.
- Título, descripción y nombres de opción llevan al lado el botón 😊 del selector de emojis.
